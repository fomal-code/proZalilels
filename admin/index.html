Import products from products.js

Copies the products hardcoded in products.js into Firestore, keeping their IDs, fields and image URLs. Products whose ID already exists in Firestore are skipped, never overwritten, so it is safe to run again.

  1. Download the backup of the original data first.
  2. Dry run to see what would be created or skipped. Nothing is written.
  3. Run migration. Each product is read back afterwards to confirm it exists.
